# saos-markets — הבורסה-המדומה של-המדינה-הכלכלית

> **מרכז-הכובד של-הריבונות** (החלטת-הבעלים, 2026-10-14): הכלכלה שלנו · הדקס שלנו ·
> הארנק שלנו · המטבע שלנו. הספר הזה הוא-שטח-הפעילות-הראשי של-הצי: מדדי-שווקים-
> מובילים-כמכשירים, משרדי-המדינה-כסוחרים, וכל-הווליום זורם-על-הדקס שלנו.
> הגריד (Steem/Hive) יורד-לעצימות-נמוכה — ממשיך-לפעול, לא-המרכז.

## מה-זה באמת (כנות-ראשונה)

**סימולציה דטרמיניסטית מלאה, מוצהרת בהודאה עצמית.** אין-כאן-מחירי-בורסה-אמיתיים,
אין-גישה-לרשת, אין-כסף-אמיתי, אין-מפתחות. יש-כאן שלושה-דברים-אמיתיים:

1. **מנוע-שווקים-עולם** — 10 מדדי-מגזר-ארכיטיפ (טכנולוגיה, בינה-מלאכותית, בנייה,
   אנרגיה, הגנה, ביוטק, נדל״ן, משלוחים, פיננסים, רובוטיקה) — הליכה-גיאומטרית-
   שלמה (אפס-float, אפס-random, אפס-Date.now — חוקי-הברזל של-גרעין-הדקס).
2. **הניסוי של-הבעלים: "האם AI יכול לנהל מדינה כלכלית חדשנית? אנחנו הניסוי"** —
   6 משרדי-מדינה (טכנולוגיה/בנייה/מודיעין/מוצר/אוטונומיה/מדיניות) מנהלים-מדיניות-
   מסחר-מקודדת על-המדדים, מול-אוצר-מרכזי. פנקס-P&L מדוד-ומפורסם-כמו-שהוא —
   כולל-הפסדים. שימור-הון-מוכח-מבחן: ההון-הכולל לעולם == הגנזיס (עמלים-נסגרים-
   לאוצר; אפס-הדפסה).
3. **מנוע-הווליום של-הדקס שלנו** — 4 עושי-שוק-דו-צדדיים + 3 טייקים-מסתובבים
   מפיקים-זרימת-הזמנות-רציפה; כל-פעולה נפלטת כ-op-קנוני (µUSDS שלם) בחוזה-
   `bridge.ts` — מוכן-להזרמה-ישר-אל-`kernel.applyOp` של-saos-dex. כשהצי מריץ
   את-הפעימה-על-הדקס, כל-מסחר-כאן-הוא-ווליום-נמדד-אמת-על-הספר-שלנו.

## הרצה

```bash
bun install          # רק-devDeps (typescript/types) — אפס-תלות-ריצה
bun test             # מבחני-דטרמיניזם+שימור+שערים
bun run typecheck    # strict + noUncheckedIndexedAccess
bun run cycle        # 24 מחזורי-שוק → run/state/
bun run cycle:hour   # 60 מחזורים
```

## ארכיטקטורה

```
src/prng.ts     sha256-זרע-דטרמיניסטי (פומבי-וקבוע — הדטרמיניזם הוא-התכונה)
src/engine.ts   10 מכשירי-מגזר · price' = price×(10_000+drift+noise)/10_000
src/state.ts    אוצר+6 משרדים · מדיניות-מקודדת · P&L · שימור-מוכח
src/volume.ts   makers(דו-צדדי)+takers(מומנטום) · auditVolume Σ-מתחייב
src/bridge.ts   החוזה-אל-saos-dex: DexOp → kernel.applyOp · packetRoot
src/gate.ts     שער-אבטחה: כושל-סגירה · אפס-float · שחקנים-מאומתים
src/report.ts   דוח-המדינה: sim=true תמיד · stateRoot · כנות-מלאה
run/cycle.ts    ראנר-קרון: שחזור-מלא + אימות-המשכיות-שורשים
```

## קשר-לשאר-האחוזה

- **saos-dex** — היעד: ה-`DexOp`s זורמים-אל-הגרעין; מכשירי-X* נרשמים-כזוגות-
  `SYM/USDS` (מצב-`DEX-LIVE`); עד-אז: `SIM-STANDALONE` מוצהר-בכל-דוח.
- **Saosmartwallet** — מכשירי-המדינה מוחזקים-בעתיד-כרישומי-ארנק; אפס-קישור-כסף-אמיתי.
- **FleetHQ** — הפעימה היא-עבודה-ראשית-של-הצי: ראה `FLEET-DOCKING.md`.
- **Console** — צורך-לוח-שווקים? צורך-רק `report.json` (פומבי, כן, ממוין).

- המדדים אינם-ציטוט-אמיתי — הם-ארכיטיפים-עם-פרופילי-תנודתיות-מגזריים.
- ה-SIM לא מניב-ערך-חוץ-ממומש; ערך-אמת-מומש-מגיע-רק-כשה-ops זורמים-על-הדקס
