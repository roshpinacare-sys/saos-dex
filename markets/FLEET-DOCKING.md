0 * * * * cd /path/to/saos-markets && bun run cycle:hour >> run/cron.log 2>&1

# הגריד — עצימות-נמוכה: פעם-ביום (מורידים-את-הפעימות-השעתיות-של-הגריד)

(יציאה-1) ולא-מדווח-הצלחה-כוזבת (חוק-לולאת-המשוב: אסור-לדווח-כשל-כהצלחה).

## חוזה-ההזרמה אל-הגרעין (מצב DEX-LIVE)

1. ריצת `runCycle()` מניבה `bridge.ops` (µUSDS שלם; `base/quote/qty/priceMu/actor`).
2. הזרמה: עבור-כל-op → `kernel.applyOp` עם:
   - `order` → op-`order` (side/qty/priceMu) על-הזוג `base/USDS`;
   - `cancel` → op-`cancel_all` לשחקן-על-הזוג.
3. השחקנים (`maker-alef`…`taker-zayin`) חייבים-מלאי-מתורגם-מתקציבי-המשרדים —
   מיפוי-1:1 מפנקס-`state.ts` (שימור-מוכח-מבחן; אין-הדפסה).
4. אימות-פלט: stateRoot-דקס עולה; ווליום-נמדד-במדדי-הדקס (לא-בדוח-הזה-בלבד).
