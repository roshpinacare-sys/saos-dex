# SECURITY — עמדת-אבטחה (מענה-ישר-לאזהרת-הבעלים)

> הבעלים: "אבטחה זהירות מקוד נגוע מקורות לא מוכרים עוקצים בקריפטו פריצות
> דרך ב-EVM ופיתוח מוצר חדשני ב-EVM".

## ההגנות-הממדדות של-הספר הזה

1. **אפס-תלות-ריצה** — הקוד-החי לא מייבא-שום-חבילה-חוץ (רק `node:crypto`).
   אין-מה-להרעיל: שרשרת-האספקה-ריקה-מעצמה. devDeps: typescript+types בלבד.
2. **אפס-fetch/eval/import-דינמי/WebSocket** — נאסר-מונרכית-בקוד ובמבחנים;
   המנוע-ניזון-מזרעים-פנימיים-קנוניים-בלבד.
3. **אפס-סודות** — בספר אין-מפתחות-פרטיים, אין-WIF, אין-.env; עיגון-עתידי-על-
   שרשרת-אמת יעבוד-אך-ורק-דרך-כספת-האחוזה (vault-home) מחוץ-לספר הזה.
4. **שלמים-בלבד** — כל-נתיב-כספי µUSDS-שלם; גבולות-גודל-מאומתים (G4) —
   חיסול-מחלקת-באגי-overflow/float-עיגול שה-EVM-אקספלויטים אוהבים.
5. **כושל-סגירה** — כל-קלט-חוץ (אם-יהיה) עובר-`gateTradeIntent`; חסימה
   נרשמת-ב-fenceRecord (מדידה-כנה, לא-שתיקה).
6. **כללי-עוקצים-בקריפטו (מדיניות-קבלה-לעתיד)**:
   - אימות-חתימות-רק-דרך-ספריות-מבוקרות-של-האחוזה (saos-dex/signer) — לא-
     קוד-מקורות-לא-מוכרים.
   - כל-חוזה-EVM-עתידי: קריאה-לפני-שליחה (eth_call), סימולציה, תקרת-גז-קשיח.
   - אישור-כתובת-מציג-וראיית-קוד-מקור-מאומת לפני-אינטראקציה-כלשהי.
   - אין-approve-בלתי-מוגבל-אי-פעם; אין-חתימה-על-הודעות-מטעם-צד-שלישי.
7. **כלל-המשחזר** — שורשי-השחזור (roots) הם-האמת: אם-משהו-משתנה-בשתיקה,
   הראנר-צורח-DIVERGED-ועוצר (אפס-סטייה-שקטה).
