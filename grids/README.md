# GRIDS — רשת-הטריגרים · דבר-גורר-דבר (fleet-2-d)

> **הרעיון (מהבעלים):** "לייצר רשת של דבר-גורר-דבר אשר מייצרת לעצמה טריגרים.
> הטריגרים מריצים את כל המערכת וככה הכל זורם. הסוכנים הם מבצעים כלכליים —
> הם מקימים גרידים ומיקרו-גרידים ומפעילים את הרשת."

## הארכיטקטורה בקצרה

```
מדידות-אמת (Steem RPC · דוח-עיגון-weave)
        │
        ▼
  אירועים (events.jsonl)  ◄──────────────┐
        │                                │
        ▼                                │
  כללים (rules.mjs · DAG)  ──פעולות──►  engine.mjs ──► אסטרטגיות (strategies.mjs)
        │        ▲                                              │
        └────────┘  האירועים-שהפעולות-מייצרות                    ▼
                   נכנסים-חזרה-ללולאה                  פקודות → מילויים → מד-עמלות
                                                            │
                                        אבן-דרך-עמלות ──────┘ → הולדת מיקרו-גריד הבא
                                                                  (רשת-שמרחיבה-את-עצמה)
```

**דבר-גורר-דבר בפועל:** עיגון-חדש ב-weave → רענון-ציטוטים → מילוי → איזון-מלאי →
עמלה-נמדדת → אבן-דרך → הולדת-מיקרו-גריד → ציטוטים-חדשים → … (חסום-עומק: 8,
חסום-הצתות: 64 לטיק — לולאה-שגשגת אבל לא-בלתי-נשלטת).

## המיקרו-גרידים (הסוכנים-כמבצעים-כלכליים)

| גריד | אסטרטגיה | מה-הוא-עושה | נולד-כש |
|---|---|---|---|
| `mm-core` | mm-grid | מייקר מדורג 3-רמות/צד סביב ה-ref | מהיום (חי) |
| `anchor-q` | anchor-quote | ציטוט-רענון על כל-עיגון-weave | מהיום (חי) |
| `micro-arb` | micro-arb | קונה-זול/מוכר-יקר בסטיית-פאריטי >25bps | אבן-דרך 1000µ |
| `sweep` | sweep | קציר-פיזור כשהספר מתרחב >80bps | אבן-דרך 2000µ |
| `mm-variant-2` | mm-grid(רחב) | מייקר שכן ברוחב-100bps | אבן-דרך 4000µ |

**ההרחבה-ממומנת-עצמה:** מיקרו-גריד חדש נולד **רק כשמד-העמלות מגיע לאבן-הדרך**
(אותה-משמעת feeMeter של `LIQUIDITY_STRATEGY.md` — אין-הדפסה-עצמית לתמריצים).
ככה "דבר גורר דבר" גם בכלכלה: עמלות → קיבולת → עמלות.

## כנות (בלי שקרים — החוקה של המודול הזה)

1. **מחיר אמת או כלום.** `refPrice` נמדד מ-`condenser_api.get_feed_history`
   (RPC ציבורי). נפילה → מדידה-אחרונה עם `stale:true` → הגרידים ידיים-בכיס.
   אף-שורה במודול לא ממציאה מחיר.
2. **אפס-אמת נשאר אפס-אמת.** עד שהמפעיל יחמש את המכונה (מפתח-active בסשן-הסנדבוקס,
   דוקטרינת R81) — כל מילוי הוא סימולציה מסומנת `sim:true`, ו-P&L-אמת (`realMu`)
   נשאר 0. הפרדה מוחלטת בכל דוח.
3. **עמלות נספרות רק ממילויים שהתרחשו.** אין-הטבות, אין-תחזיות-כמדידה.
4. **דטרמיניזם.** אותו-זרע + אותם-קלטות → אותו-עולם. PRNG מזורע בלבד.
5. **מגני-לולאה.** עומק-שרשור 8, הצתות 64/טיק, חריגה → `grid.halt` + יציאה 2.

## שימוש

```bash
node grids/run.mjs                 # טיק אחד (זה מה שה-Action מריץ כל-30 דק')
node grids/run.mjs --loop 60000    # לולאה אוטונומית מקומית (עם backoff)
node grids/run.mjs --selftest      # הוכחה עצמית: 20 טיקים + אסרטים
```

מצב: `grids/state/state.json` (מחויב) · יומן: `grids/state/events.jsonl` (מקומי) ·
P&L: `grids/state/pnl.json` (מקומי).
