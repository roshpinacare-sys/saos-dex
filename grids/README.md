# GRIDS — רשת-הטריגרים · דבר-גורר-דבר (fleet-2-d)

> **הרעיון (מהבעלים):** "לייצר רשת של דבר-גורר-דבר אשר מייצרת לעצמה טריגרים.
> הטריגרים מריצים את כל המערכת וככה הכל זורם. הסוכנים הם מבצעים כלכליים —
> הם מקימים גרידים ומיקרו-גרידים ומפעילים את הרשת."

## הארכיטקטורה בקצרה

```
מדידות-אמת (Steem RPC · דוח-עיגון-weave)
        │
        ▼
  אירועים (events.jsonl)  ◄──────────────┐
        │                                │
        ▼                                │
  כללים (rules.mjs · DAG)  ──פעולות──►  engine.mjs ──► אסטרטגיות (strategies.mjs)
        │        ▲                                              │
        └────────┘  האירועים-שהפעולות-מייצרות                    ▼
                   נכנסים-חזרה-ללולאה                  פקודות → מילויים → מד-עמלות
                                                            │
                                        אבן-דרך-עמלות ──────┘ → הולדת מיקרו-גריד הבא
                                                                  (רשת-שמרחיבה-את-עצמה)
```

**דבר-גורר-דבר בפועל:** עיגון-חדש ב-weave → רענון-ציטוטים → מילוי → איזון-מלאי →
עמלה-נמדדת → אבן-דרך → הולדת-מיקרו-גריד → ציטוטים-חדשים → … (חסום-עומק: 8,
חסום-הצתות: 64 לטיק — לולאה-שגשגת אבל לא-בלתי-נשלטת).

## המיקרו-גרידים (הסוכנים-כמבצעים-כלכליים)

| גריד | אסטרטגיה | מה-הוא-עושה | נולד-כש |
|---|---|---|---|
| `mm-core` | mm-grid | מייקר מדורג 3-רמות/צד סביב ה-ref | מהיום (חי) |
| `anchor-q` | anchor-quote | ציטוט-רענון על כל-עיגון-weave | מהיום (חי) |
| `micro-arb` | micro-arb | קונה-זול/מוכר-יקר בסטיית-פאריטי >25bps | אבן-דרך 1000µ |
| `sweep` | sweep | קציר-פיזור כשהספר מתרחב >80bps | אבן-דרך 2000µ |
| `mm-variant-2` | mm-grid(רחב) | מייקר שכן ברוחב-100bps | אבן-דרך 4000µ |

**ההרחבה-ממומנת-עצמה:** מיקרו-גריד חדש נולד **רק כשמד-העמלות מגיע לאבן-הדרך**
(אותה-משמעת feeMeter של `LIQUIDITY_STRATEGY.md` — אין-הדפסה-עצמית לתמריצים).
ככה "דבר גורר דבר" גם בכלכלה: עמלות → קיבולת → עמלות.

## כנות (בלי שקרים — החוקה של המודול הזה)

1. **מחיר אמת או כלום.** `refPrice` נמדד מ-`condenser_api.get_feed_history`
   (RPC ציבורי). נפילה → מדידה-אחרונה עם `stale:true` → הגרידים ידיים-בכיס.
   אף-שורה במודול לא ממציאה מחיר.
2. **אפס-אמת נשאר אפס-אמת.** עד שהמפעיל יחמש את המכונה (מפתח-active בסשן-הסנדבוקס,
   דוקטרינת R81) — כל מילוי הוא סימולציה מסומנת `sim:true`, ו-P&L-אמת (`realMu`)
   נשאר 0. הפרדה מוחלטת בכל דוח.
3. **עמלות נספרות רק ממילויים שהתרחשו.** אין-הטבות, אין-תחזיות-כמדידה.
4. **דטרמיניזם.** אותו-זרע + אותם-קלטות → אותו-עולם. PRNG מזורע בלבד.
5. **מגני-לולאה.** עומק-שרשור 8, הצתות 64/טיק, חריגה → `grid.halt` + יציאה 2.

## שימוש

## הקשר-היסטורי (למה זה קם עכשיו)

THE-REAL-GRID (`grid-beat` עם מפתח-active של @headcorner) מת עם מכסת-הדקות
של Actions ב-2026-09-20 — המכונה **חמושה-וחסומה**, לא-מנוטרלת. הרשת-הזאת היא
שכבת-הפאבריק שנשארת-חיה חסרת-מפתחות: מודדת, מציתה, מתמרגלת, ומפרסמת את
המצב — כך שברגע שהמפעיל מחזיר דלק (מפתח + הון), הטריגרים כבר זורמים והמכונה
מתחברת לתוך זרימה-חיה במקום-להתחיל-מאפס.

## מנוע-הצמדה (B-1 · fleet/r130): פרמטרי-גריד פנים → הצעה חוץ

`grids/peg.mjs` הוא החוליה שסוגרת את הלולאה: המיקרו-גרידים מריצים כלכלה
פנימית (סימולציה `sim:true`), והמנוע הזה מתרגם אותה ל**הצעה-חוץ**
`grids/state/offer.json` — תוכנית-פקודות ביחידות-אמת (STEEM/SBD) שניתנת
לביצוע על-ידי המוביל (R81, שער-מפעיל) ולאימות על-ידי כל אחד.

```
מדידות-אמת                          צורה (הגרידים הפנימיים)
├─ feed_price (פנים, פנים-אמת)      ├─ levels / widths / symmetry
├─ פאריטי-USD (חוץ, גבול-ערך)  ──►  ├─ דוקטרינת-הפאריטי
├─ יתרות-שרשרת (הון-אמת)            └─ מגני-מלאי (אין-עירום)
└─ ספר-טריגרים (Z-4/Z-5)
        │
        ▼
  offer.json (מציע — לא חותם) ──► offer.published/blocked → יומן-האירועים
                                    (ההצעה עצמה הופכת טריגר לדבר-הבא)
```

**חמשת העקרונות** (בראש `peg.mjs`): מחיר-אמת או כלום · דוקטרינת-הפאריטי
(אף-מכירה מתחת לערך-החוץ, אף-קנייה מעליו, רצועת-סירוב 5000bps) · חסר-מפתחות
מהיסוח · אין-מכשור-עצמי (מלאי-µ פנימי הוא צורה בלבד ואינו מנפח גדלים) ·
דטרמיניזם מלא (הזמן מוזרק).

```bash
node grids/peg.mjs               # ריצת-הצעה אחת (מדוד → חשב → פרסם → הצת)
node grids/peg.mjs --selftest    # 31 וקטורים דטרמיניסטיים (B-1+B-3), אפס רשת
```

מסמך-ההצעה: `grids/state/offer.json` (מחויב כעדות בכל-ריצה · verdict
`OFFER-READY`/`OFFER-BLOCKED` + חסמים-כנים תמיד מפורשים).

### B-3 (fleet/r130): סולם-5-רמות + גרירה-דינמית

ברירת-המחדל עלתה ל**5 רמות-לצד**, והגרירה-הדינמית הופכת את ריחוק-הרמות
לפונקציה-נמדדת של פיזור-הספר-החי (אותה-גרירה שהמוביל R81 מבצעת — כאן
פורמולה גלויה):

```
dragK = clamp(1 + spreadBps / 2000, 1, 3)
```

אין-ספר → k=1 (ניטרלי) · פיזור-2000bps → k=2 · תקרה חסומה k≤3.
המכנה המלא מפורסם בתוך `offer.json` (`drag:`) — נמדד, לא נסתר.
ההצבה-בפועל על-השרשרת נשארת **שער-מפעיל** (X-1).

## Z-87a — קו-הארביטרז' והניתוב (ריבוני · plan/scan-ONLY · אפס-ביצוע)

הרחבת-ה-DEX (audit-Z86c פערים b–e + תיקון-S): כל-המודולים חסרי-מפתחות,
דטרמיניסטיים, מקבלות-בלבד. אף-מספר לא מומצא; פיד-שנכשל → רשומה-דגרדד/חסימה
כנה (fail-closed). הביצוע נשאר שער-בעלים בלבד.
