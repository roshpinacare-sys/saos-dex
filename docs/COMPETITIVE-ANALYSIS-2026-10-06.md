# ניתוח-השוואתי מול ה-DEX-ים המובילים — מה חסר, מה מומש (2026-10-06, Task 83)

**שאלת-המפעיל:** "מה חסר לנו בעצם כדי לעבוד כמוהם **חוץ מנזילות**? מבחינה טכנית ועוד. בוא נבצע שיעבוד לפחות כמוהם או יותר מהם."

**תשובה-קצרה:** הפערים-הטכניים-חוץ-נזילות היו: ממשק-מסחר (נרות/עומק), סוגי-פקודות
מקצועיים, סטרימינג, היסטוריה-מנותבת וסטטיסטיקת-שוק. **כולם מומשו היום** (Task 83,
saos-dex/1.19.0+cex-grade-marketdata). הפער-הפתוח-היחיד = עומק-נזילות (והוא מטופל
ארכיטקטונית ע"י ALE/POL — צמיחה-מעמלות-אמת).

## 2. מה מומש היום (Task 83 — קומיט `cex-grade-marketdata`)

1. **מודול נרות `src/lib/dex/klines.ts`** — OHLCV דקה-בסיס (4,320 נרות=3-ימים פר-זוג)
   מ**מסחר-אמת בלבד** (fill+swap; אפס-נרות-מזויפים), חוץ-מצב קנוני (לא-נוגע-ב-stateRoot),
   **מוצמד-לגיט** (`db/klines.json` נעקב — שורד מחיקת-סנדבוקס, חוזר ב-clone/heal),
   הזנה-מ-buildBlock, שטיפה-עם-התמונה.
2. **`GET /api/dex/klines`** — טווחים 1m/5m/15m/1h/4h/1d, cursor-pagination (before),
   limit≤1000. **`GET /api/dex/trades`** — טבעת-2,000-עסקאות פר-זוג עם cursor.
3. **`GET /api/dex/stream`** — SSE: פעימת-2ש׳ (גובה, מחירים, 24h, 5-עסקאות) —
   HTTP-ילידי, retry-סטנדרטי, עובר-גייטוויי.
4. **גרף-נרות + נפח** (lightweight-charts v5 — אותו-סטנדרט-TradingView של-המובילים)
   + **גרף-עומק** SVG עם מד-imbalance + מתגי-טווח (CANDLES/DEPTH · 1m–1d).
5. **סוגי-פקודות מוסדיים בגרעין** (דטרמיניסטיים-מלא, אפס-float):
   - `postOnly` — maker-only: סריקת-שלמים לפני-כל-נגיעה-במצב; חוצה → דחייה-נקייה.
   - `ioc` — Immediate-Or-Cancel: שארית-שלא-חצתה מתבטלת-בכנות (שחרור-ערבות-מדויק,
     journal-עדה; אין-פקודה-נחה).
   - `oco_place` — stop+take מקושרים: ירי/פקיעה/ביטול-רגל אחת מבטלת-את-האחות
     (trigTick+trig_cancel; ערבות-פר-רגל — אותו-חוזה-escrow של-טריגר-בודד).
   - סטטיסטיקת-**24ש'** פר-שוק (chg/high/low/vol/trades) ב-/state · watchlist · header.
6. **UI** — טופס-מסחר: LIMIT/MARKET/STOP/TAKE/OCO + POST-ONLY/IOC toggles;
   watchlist ו-header מציגים 24h-חי.
7. **`/api/dex/compare`** — 5-שורות-השוואה-חדשות עם הערכים-הנמדדים.

## 4. המסקנה-הטכנית

מבחינת-**מנוע** (התאמה, אטומיות, ביקורת-שלמות, דטרמיניזם, סוגי-פקודות) ומבחינת
**ממשק-מסחר** (נרות, עומק, סטרימינג, היסטוריה, 24h) — SAOS-DEX מגיע-היום לסטנדרט
של-המובילים, ו**עולה-עליהם** ב: גז-אפס-אמיתי, MEV-אפס-מבני, עמלות-דינמיות-אנטי-LVR,
CoW-ברירת-מחדל, POL-צומח-מעמלות, אימות-עצמאי-מרקל, עיגון-חוץ-חי, וריבונות-גיט
(המצב שורד-מחיקת-תשתית — דבר שאף-מתחרה לא מציע כי הם תלויי-שרשרת-חוץ).

הפער-היחיד-שנותר = **נזילות-עומק** — והוא לא-בעיה-קוד אלא עניין-זמן/הון, ומטופל
כבר-בארכיטקטורה (ALE: כל-עמלה מעמיקה-את-ה-POL; דלת-המטבעות: גיבוי-מרשתות-חוץ).
