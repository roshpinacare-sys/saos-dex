## 2. איפה הענקים מרוויחים — ומה אנחנו לוקחים מזה (בכנות-קנה-מידה)

1. **רוחב-עדין + עומק מדורג** (Jump/Citadel style): ציטוט צמוד כשמלאי-נייטרלי, עומק
   גיאומטרי מאחורי הרמה-הראשונה → `supremacyTick` (widthBps 40–64, growth 1.3–1.4).
2. **הטיית-מלאי** (Avellaneda–Stoikov): הציטוטים רודפים מלאי-יעד-אפס → `inventorySkew`.
3. **התרחבות-מעמלות** (מודל-עמלות של AMM-ים): מיקרו-גריד-חדש נולד רק-מעמלות-שנמדדו →
   `feeCompound` + R-FEE-SPAWN ברשת-הטריגרים.
4. **זמינות-ציטוט** (redundancy): כשמייקר-אחד נעצר, הרשת לא נשארת חשופה — 4+ חיילים
   על-סולם-המחיר → `fleetSpawn` + סולם-רוחבים ב-state.
5. **מדידה-חוצה-סביבות**: אותו-זרע → אותם-מספרים בסנדבוקס ובענן — שחזור הוא
   הקבלה → `mulberry32` + receipts.

20. **סולם-הון-אמת:** MISSION-1000 דורש הון-לפי-APR — מה קצב-הוספת-חיילים ששומר על רווחיות-ל-μ-יחיד (לא רק ווליום-מצטבר)?
21. **✅ נמסר Z-77:** חוקים-קבועים חדשים נכנסו ל-selftest: "סך-המלאי של כל-הצי ≤ תקרה-גלובלית (רך) / 2× (קשה)" + "אף-נתיב לא מחזיר halted-עם-מלאי" + "פריקת-חייל-ריק לא מוסיפה-מלאי".
