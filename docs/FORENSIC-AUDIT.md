## 2. ממצא קריטי #1 — כספת המפתחות פתוחה לחלוטין

**מיקום:** `saos-sovereign-platform/agent/keys/`

| קובץ | גודל | תוכן |
|---|---|---|
| `fleet_keys.enc` | 170,905 bytes | 7 מפתחות מוצפנים (scrypt 2^14 + AES-256-GCM, פורמט SAOS-FLEET-VAULT-1) |
| `fleet_keys.meta.json` | 193 bytes | **מכיל את סיסמת הכספת בשדה `pass` — בטקסט גלוי** |

### למה זה קריטי
ההצפנה עצמה טובה (scrypt + AES-256-GCM זה סטנדרט ראוי). אבל **הסיסמה יושבת בקובץ הצמוד**. זו לא הצפנה — זו נעילה עם המפתח מתחת לשטיח.

**רמת חשיפה:** כל גישת קריאה לריפו, כל token שדלף אי-פעם, כל סוכן עם הרשאות — יכול לפתוח את כל 7 המפתחות.

> ערך הסיסמה עצמו **לא** שוכפל במסמך זה. רק מיקומו. מחיקה מ-HEAD לא מסירה אותה מהיסטוריית git — אם הריפו אי-פעם שותף או נסרק, הסיסמה חשופה היסטורית.

### פעולה מיידית (סדר מחייב)
1. **הנח שכל 7 המפתחות שרופים.** לא "אולי". שרופים.
2. **סרוק את 4 הכתובות בסעיף 5** — אם יש יתרה כלשהי, העבר לארנק חדש שנוצר על מכשיר נקי.
3. **מחק את `agent/keys/` מהריפו.**
4. **לעולם אל תשמור סיסמת כספת באותו עץ קבצים כמו הכספת.** משתנה סביבה בלבד.

## 6. ממצא נוסף — ה-token שהודלף היה בעל הרשאות מלאות

ה-PAT שנחשף בשיחה היה **classic token עם סקופים מקסימליים**, כולל:
`repo`, `delete_repo`, `admin:org`, `admin:public_key`, `admin:ssh_signing_key`, `workflow`, `write:packages`, `codespace`, `audit_log`, `user`.

**משמעות:** מי שמחזיק אותו יכול למחוק ריפואים, לשנות ארגון, להוסיף מפתחות SSH, ולהזריק workflows. זה לא token לקריאה — זה מפתח מאסטר.

**פעולה:** בטל אותו עכשיו. אם בעתיד נדרש token לסוכן — **fine-grained, Contents: read/write על ריפו יחיד בלבד, תוקף קצר, בלי workflows ובלי admin.**

## 7. מה דווקא כן אמיתי וטוב

קוד נקרא ישירות, לא הודעות קומיט. ב`saos-sovereign-foundry`:

**`src/lib/saos/merkle.ts` — תקני ונכון:**
- עץ SHA-256 עם שכפול אי-זוגי תקני (`tree[n-1]=tree[n-1]`)
- `merkleProof()` מייצר path אמיתי עם `dir` מפורש
- `verifyMerkleProof()` — אימות עצמאי ללא אמון בשרת

**`src/lib/saos/kernel.ts` — דטרמיניזם אמיתי:**
- טבלת GAS קפואה (`stamp:20, seal:60, harvest:20, wallet:40, relay:0`)
- `applyTx()` — זורק חריגה, **אף פעם לא מתדרדר בשקט**
- מניעת replay אמיתית (`issuer:nonce` Set)
- שימור ערך אמיתי (יתרה לא מספיקה → throw)
- `stateRoot = sha256(canonical(state))` — canonical JSON מלא (key sort, `-0`→`0`, finite guard)
- `replay()` — שחזור מלא מלוג טרנזקציות
- selftest עם 7 בדיקות תכונות אמיתיות (דטרמיניזם, רגישות לסדר, שימור supply, עמידות ל-replay)

**זה נכס הנדסי אמיתי.** הבעיה היא לא איכות הקוד — הבעיה היא **המשילות**.
