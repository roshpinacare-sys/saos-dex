# Maker-API — ממשק-מייקרים-מקצועי (EXEC-CD-8, 2026-10-06)

**המטרה** (החלטת-מפעיל: "בוא נבצע שיעבוד לפחות כמוהם או יותר"): המאפשר-הקודי
לפער-הנזילות — למשוך מייקרים-מקצועיים עם אותו-משטר-API שבורסות-המובילות
(dYdX · Hyperliquid · Binance) — על ספר-דטרמיניסטי בגז-0 עם MEV-אפס-מבני.

## הנקודות-החיות

| מסלול | שיטה | אימות | מה-עושה |
|---|---|---|---|
| `/api/dex/maker/quotes` | POST | `x-saos-operator` | הצבת-עד-8-ציטוטים בשליחה-אחת |
| `/api/dex/maker/cancel-all` | POST | `x-saos-operator` | סוויפ-ביטול-כל-הפקודות (רשות: סינון-זוג) |
| `/api/dex/maker/refuel` | POST | `x-saos-operator` | מסילת-דלק-למייקר (סולם-הממנים, אפס-הטבעה) |
| `/api/dex/maker/snapshot` | GET | ציבורי (שקיפות) | פקודות-חיות + ייחוס-מילויים + מסגרת-ריבייט |

כל-POST דורש גם `x-saos-dex-console: 1` (שער-CSRF — כמו-כל-המוטציות).

## POST /api/dex/maker/quotes

```json
{
  "mode": "atomic",            // atomic (ברירת-מחדל) | best-effort
  "orders": [
    { "base": "SAOS", "quote": "USDS", "side": "buy",
      "price": 1318, "amount": 50000, "postOnly": true },
    { "base": "SAOS", "quote": "USDS", "side": "sell",
      "price": 1326, "amount": 50000, "postOnly": true }
  ]
}
```

- **atomic** — batch-אטומי-גרעיני (הכל-או-כלום): ציטוט-אחד-פסול (למשל postOnly-חוצה)
  מדחה את-כולה → אפס-גריד-חצי-ממוקם. הגנת-מלאי.
- **best-effort** — שליחות-נפרדות; תוצאה-פר-ציטוט (רענון-מדורג).
- פר-ציטוט: `postOnly` (מסרב-לחצות) · `ioc` (מיד-או-ביטול) — לא-יחד.
- ≤8-ציטוטים (BATCH_MAX_OPS — תקרת-הגרעין-האטומי).

## POST /api/dex/maker/cancel-all

```json
{ "base": "SAOS", "quote": "USDS" }   // רשות — בלי-גוף = כל-השווקים
```

- רץ **בזמן-בניית-הבלוק** — מוחק את-מה-שחי-אז → **אפס-מירוץ** מול-מילויים
  (המירוץ הוא-החולשה-המוכרת של cancel-by-id בבורסות-REST).
- אידמפוטנטי: אין-פקודות = ok. שחרור-ערבויות מדויק-פר-פקודה (מד-אסקרו-פרטי).
- גז 15 — כמו-ביטול-יחיד (מעודד-סוויפ על-פני סדרת-ביטולים).

## GET /api/dex/maker/snapshot

```json
{
  "ok": true, "issuer": "operator", "liveOrders": 4, "orders": [...],
  "stats": { "fills": 12, "volMu": 184000, "rebateRateBps": 0,
             "rebateDueMu": 0, "rebatePaidMu": 0 },
  "recentFillsAsMaker": [...]
}
```

## מסגרת-הריבייט — כנות-מלאה

- הייחוס **ממסחר-אמת בלבד**: כל-fill עם-attribution maker (אותם-אירועי-גרעין
  שמזינים-את-הנרות) → `fills`, `volMu` (נומינל-ציטוט µ) פר-מנפיק.
- הנתונים **חוץ-מצב קנוני** (אותו-משטר של-הנרות): לא-נוגעים ב-stateRoot,
  השרשרת-החיה-ממשיכה-בשלמות. מוצמד-לגיט: `db/maker-stats.json` — שורד-מחיקה.
- **תעריף = 0 עכשיו**: הספר **לא גובה עמלת-taker** (Roast-64 — עלות-אמת אפס),
  ולכן אין-מקור-מימון-עצמי. מקור-מימון אפשרי (החלטת-מפעיל, מדיניות-ריבונית):
  (א) מנת-עמלות-בריכות · (ב) מענק-אוצר-מדוד. המסילה-חיה:
  `rebateDueMu = floor(volMu × rateBps / 10_000)` — כשהתעריף ייפתח, החוב-נמדד
  מיידית מההיסטוריה-המצטברת.

## מדידת-אמת (2026-10-06, EXEC-CD-8)

- **הגרעין מוכח**: 21/21 בדיקות-קלון-דטרמיניסטיות (harness/maker-kernel-test.ts) —
  batch-אטומי (הצבה+דחייה-מלאה-בלי-שריפת-גז) · cancel_all-סוויפ עם-שחרור-אסקרו-מדויק ·
  סינון-זוג · אידמפוטנטיות · ריפליי-נדחה.
- **ממצא-מבני-חי**: כלכלת-הדלק-במצב-קיפאון-נמדד (אפס-fills/swaps, feeMeter-על-רצפת-
  8000, כל-ממני-הסולם-על-FUNDER_KEEP). השורש: הספר-גובה-גז (order=60) אבל-המזרקה
  ממחזרת **רק-עמלות-בריכות** — גז-הספר-עצמו-בורח-מהמחזור → מלכודת-מוות-דלקית-איטית
  בכלכלה-ספר-מרכזית-בלי-זרימה-חוץ. **התיקון-המוצע (ממתין-אישור-מפעיל)**: הארכת-
  המזרקה למחזר-גם-גז-ספר-שנגבה (מד-חוץ-מצב-דטרמיניסטי, נבנה-מחדש-בריפליי; כל-µ-
  נגרע-פעם-אחת; אפס-שינוי-בשורש-המצב). עד-אז: ה-API-כנה — מסלול-ה-refuel מדווח
  "no-funder-can-afford" במקום-לשקר.

## למה-זה-משנה (השוואה)

Uniswap/Curve — אין-ספר-בכלל (AMM): אין-למה-לצטט. dYdX/Hyperliquid — יש
Maker-API אבל על-שרשרת-חוץ-תלויה. שלנו: batch-אטומי + cancel-all-חסין-מירוץ +
ייחוס-מרקל-ניתן-לאימות + גז-0 — **סטנדרט-המובילים, והיתרונות-הריבוניים-מעליהם**.

## EXEC-CD-9 · הכלכלה-מופעלת (2026-10-06 — אישור-מפעיל "תקן הכל ולייעל")

**שלושה-שינויים-מבניים-שנכנסו-לחיים:**

1. **מחזור-גז-הספר (fuel-freeze-fix)** — `bookgas.ts` + `economy.bookGasRecycle`:
   מד-חוץ-מצב-דטרמיניסטי (`db/book-gas.json` — נעקב-גיט) של גז-הספר-שנגבה
   (order/fill/cancel/cancel_all/gc) → **כל-100-בלוקים** המזרקה מחזירה אותו לאוצר
   (סמנטיקות-mint_fuel: feeMinted↑ — האינווריאנטה Σcredits+gasUsed−feeMinted===ג'נזיס
   נשמרת-בדיוק) → האוצר מפיץ דרך-סולם-refuel. כל-µ-פעם-אחת; רצפת-מצב
   (bookGasFloor) קוטלת הטבעה-כפולה. **נמדד-חי**: 94kµ-נאספו · 78kµ-הוחזרו בשעות-הראשונות.

2. **THE-PRIMER — הצתה-חד-פעמית** — op-`primer` (אוצר-בלבד, דגל-`primerUsed`
   fail-closed, ספליט-קבוע 1Mµ לסולם-הממנים). הממצא: 28.1Mµ-גז-נשרף-וברח-מהמחזור
   בעידן-שלפני-המד (הכלכלה-כולה-על-אפס — אפילו-order_gc-של-האוצר-נדחה). הפריימר
   מוצהר-ולא-מוסתר: `primerMu` — הביקורת-מחסירה-אותו-מזהות-העמלות
   (`fees: pools === feeMeter+profit+minted−primer−bookgas+spent`). הביקורת-עצמה
   תפסה-את-הניסיון-הראשון-בלי-ההצהרה (HALT-פורנזי) — **הכשל-היה-ההוכחה-שהמערכת-עובדת**.

3. **הריבייט-והזהויות-נפתחו** — `MAKER_REBATE_BPS = 10` (0.1%-מנומינל, ממומן
   ממחזור-גז-הספר — הזרם-הסגור: מייקרים→גז→מד→אוצר→סליקה→מייקרים);
   `/api/dex/maker/rebate-settle` (סליקה-ב-refuel-טהור-אפס-הטבעה + rebateMarkPaid
   מונוטוני); `?issuer=`/`issuer:` בכל-מסלולי-המייקר — **זהויות-מייקר-חוץ** (חשבון-אזרח,
   המפתח-האחד-חתום; היגיינה-`isMakerIdentity`); refuel-מממן-זהות-חוץ (`to:`).

**ובנוסף — רישום-בריכות-חצי-פתוח (אישור-מפעיל על שינוי-המדיניות):**
`pool_open`-אזרחי: כל-אזרח פותח-בריכה על נכסים-רשומים — זריעה-דו-צדדית-מהיתרות-
שלו-עצמו, LP=√k כולו-לפותח, `owner`-נרשם-במצב. **שער-הערבות**: מינימום
50,000µ-פר-צד + תקרת-8-בריכות-פר-פותח. אפס-כסף-אוצר-בסיכון (האוצר רק מרוויח
נתח-ה-30%-מעמלות); מגן-repeg: בריכת-אזרח אינה-ניתנת-לסימון-מחדש-אוצר. הנתיב-הריבוני
(אוצר) נשאר-כמו-שהיה. הפער-מול-המובילים (רישום-פרמיסיונלי) — **סגור**.
