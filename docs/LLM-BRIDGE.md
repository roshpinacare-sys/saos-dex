## מה-יש כאן

- `grids/llm/llm-providers.mjs` — רישום-ספקים (groq, gemini, mistral, openrouter),
  סדר-עדיפות כחוזה, ניתוב-מודל `provider/model`, חוק-ההשתקה (`redact`).
- `grids/llm/llm-call.mjs` — הגשר: קריאה-אחת אפס-תלויות (node ≥ 20).
  ראשון-חמוש-שמצליח מנצח; timeout לכל-ספק; כישלון-כולל/אין-מפתח → `LLM-HOLD` (fail-closed).
- `grids/llm/llm-selftest.mjs` — 24 כללי-ברזל: fail-closed אפס-קריאות-רשת ללא-מפתח,
  סדר-עדיפות, fallback, timeout, צורות-בקשה (openai/gemini), חוק-ההשתקה, CLI HOLD.
- `.github/workflows/llm-bridge.yml` — ריבוני לגמרי (אפס-action-צד-ג):
  selftest תמיד → סטטוס-חימוש (שמות-בלבד) → קריאת-אמת אחת כשחמוש → קבלה-כנה → קומיט.

## איך-מחמשים (צעד-בעלים בלבד — הסוכנים לעולם לא רושמים חשבונות ולא עוקפים אימות)

1. בעלים נרשם-עצמו לספק-אחד או יותר (מסלול-חינם של-הספק, לפי-תנאי-השימוש שלו):
   Groq `https://console.groq.com` · Gemini `https://aistudio.google.com/apikey` ·
   Mistral `https://console.mistral.ai` · OpenRouter `https://openrouter.ai/keys`
2. בעלים מכניס את המפתח לכספת: **GitHub → roshpinacare-sys/saos-dex → Settings →
   Secrets and variables → Actions → New repository secret** (שמות: `GROQ_API_KEY`, `GEMINI_API_KEY`, `MISTRAL_API_KEY`, `OPENROUTER_API_KEY`).
3. מהרגע-ההוא הזרימה יומית (cron 05:23 UTC) מוכיחה-חיים: קריאה אמיתית → קבלה
   `grids/state/llm-bridge-receipt.json` → commit = קבלה-חיצונית.
   בלי-מפתחות: `armedCount: 0` + `hold` — כן, שקוף, ואפס-כסף.
